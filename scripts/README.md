## Scripts d’infrastructure

Voir le dossier `scripts/` pour :
- bootstrap kafka
- synchronisation openapi
- initialisation des règles

### Convention des scripts

Tout script conservé dans le dépôt doit indiquer en en-tête :
- son rôle
- son usage
- son contexte
- son statut (actif | expérimental | historique)

Un script sans intention claire est considéré archivable.
