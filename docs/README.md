## fonds de conception à conserver

Les documents binaires ou sources de conception ne sont pas des sources documentaires actives, mais ils sont conservés comme fonds de travail :

- `Document/` : documents de conception, vocabulaire, devis, suivi CORS, TUI, UI état joueur ;
- `Document/Gabarits/` : sources graphiques GIMP (`.xcf`) ;
- `Document/Archives/` : versions historiques de documents de conception ;
- `Archives/` : archives méthodologiques, notes, anciens documents et exports déjà classés.

Ces fichiers ne doivent pas être supprimés lors du nettoyage documentaire sans décision explicite. Lorsqu’un contenu devient normatif, il doit être resynchronisé vers `docs/` ou `contrats/`.
